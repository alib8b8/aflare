# Multi-Role Business Agent

三角色一体商业智能体（营销 + BD + IR），参考 xiaobei 的产品设计思路。一个入口，覆盖从内容产出、找客户、到融资材料的全流程。

## 核心能力

### 🎯 市场营销 Agent (Marketing)
- 多平台内容创作（公众号、小红书、抖音、Twitter/X、B站、知乎、LinkedIn）
- 内容日历规划
- 爆款分析和仿写
- SEO关键词优化

### 🤝 商务拓展 Agent (BD)
- 潜客挖掘和线索列表
- 竞品分析
- 个性化触达文案
- 评论区互动策略

### 💰 投资人关系 Agent (IR)
- 商业模式打磨
- Pitch Deck / 融资材料
- 财务规划和关键指标
- 投资人管道发掘
- 软著、ICP备案等申报材料

### 📊 市场研究 Agent (Research)
- 行业趋势分析
- 多平台信源聚合（14类信源）
- 真实信号排序

## 使用方式

```bash
aflare run business/multi-role-agent
```
