# Goal Setting Workbook

> Set SMART goals with action plans

## Description

This workflow template provides a ready-to-use solution for set smart goals with action plans.

## Usage

```bash
aflare install productivity-personal/goal-setting
aflare run goal-setting/workflow.yaml
```

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| - | Check workflow.yaml for configurable parameters | - |

## Nodes Used

- agent - AI agent node for intelligent processing
- template_render - Template rendering with Go templates
- file_write - Write output to files
- notify - Send notifications
- http_request - Make HTTP requests (when applicable)
- json_parse - Parse JSON responses (when applicable)
- execute - Execute shell commands (when applicable)
