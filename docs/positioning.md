# 20 Positioning Statements for llm-box

---

## Core Slogans

1. Build terminal workflows using plain English.
2. Turn repetitive terminal tasks into reusable workflows.
3. No YAML. No drag-and-drop. Just terminal automation.
4. A terminal-first workflow automation tool for developers.
5. Define what you want, not how to do it.

---

## Feature-Focused

6. Single binary, zero dependencies workflow engine for the terminal.
7. Extensible CLI tool for chaining terminal commands into workflows.
8. Save, share, and version control your automation workflows.
9. Beautiful TUI showing real-time workflow progress.
10. Cross-platform workflow automation (Linux/macOS/Windows).

---

## Problem-Solution

11. Stop writing fragile bash scripts; use structured workflows instead.
12. Escape the endless YAML configuration hell.
13. Avoid heavy GUI tools; automate from your terminal.
14. Make your terminal tasks reusable and maintainable.
15. No lock-in: all workflows are plain YAML, transparent and scriptable.

---

## Audience-Specific

16. For developers who love the terminal but hate boilerplate.
17. For DevOps engineers seeking lightweight workflow automation.
18. For open-source contributors looking to simplify their release process.
19. For technical writers automating content preparation workflows.
20. For anyone who wants to spend less time on repetitive tasks.
