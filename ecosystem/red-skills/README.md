# RED Skill 储备库

小红书 RED Skill 平台发布储备。待创作者条件满足后（实名认证 + 注册>180天 + 粉丝≥1000），可直接上传发布。

| Skill | 文件 | 目标用户 | 核心能力 |

| 鸿蒙多设备适配助手 | [harmony-device-adapt/SKILL.md](harmony-device-adapt/SKILL.md) | 鸿蒙开发者 | 输入设备类型，自动生成UI适配方案 |
| 端侧AI工作流生成器 | [ondevice-workflow-gen/SKILL.md](ondevice-workflow-gen/SKILL.md) | 移动端用户 | 自然语言生成离线AI工作流 |

## 发布步骤

1. 登录小红书创作者中心
2. 进入笔记管理 → Red Skill
3. 选择文件夹上传，提交 SKILL.md
4. 填写 Skill 名称、描述、场景标签
5. 等待审核（通常几分钟）
6. 发布笔记时挂载 Red Skill

## 小红书 RED Skill 官方要求

- 实名认证
- 账号注册时间 > 180 天
- 粉丝数 ≥ 1000
- 支持 Markdown / TXT 格式
